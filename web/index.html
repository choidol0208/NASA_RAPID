      How the score works

      Each of the 41 test configurations in the team's catalog is compared with your input on up to seven dimensions: oxygen, pressure, flow, fuel, sample shape, research purpose and, for suppression questions, the diluent gas. Each comparison gives a similarity from 0 to 1, shown as the strip on each result.

      Weights depend on the kind of question (prevention, detection or suppression). Oxygen and flow weigh most for flammability, because a microgravity flame has no buoyancy and gets its oxygen only from forced flow. A wrong fuel phase or a far-off oxygen level cannot be made up by other matches. The total is then scaled by evidence quality (raw data, flight duration, human check).

      The same code ranks every query. A language model never produces or changes a score. Catalog values are extracted from the PSI records and tables and are marked when not yet checked by a person.

      This page, the catalog, the ranking code and the data pipeline were written with an AI assistant (Claude) under the team's direction. Text written by a language model carries an "AI-generated" label that says whether a person has checked it against its source. The repository lists every AI use and every source.
